What is Exception?
- Its an event that occur during the execution of the program
- It will disrupt your program normal flow.
- It creates the exception object which contain information about the erroe like
  -> Its type of exception
  ->stack trace etc 
- Runtime system use this exception object and find the class which can handle it


-> Errors generally represent serious JVM/system-level problems that applications are not expected to recover from, 
while exceptions represent conditions that applications can often handle.

Why is Throwable the parent of both Error and Exception?

Because Java has two categories of abnormal conditions:

Exception → conditions an application may reasonably handle.
Error → serious problems generally outside application control.


-->throws does not actually throw the exception.

It says:

"This method may throw this exception. Whoever calls me needs to deal with it."

So:

throws
   ↓
Declaration / warning to caller

Whereas:

throw
   ↓
Actually creates/throws exception


-->finally normally executes regardless of whether an exception occurs or whether the exception is caught, 
but it may not execute if the JVM terminates abruptly, such as through System.exit() or a JVM crash.
